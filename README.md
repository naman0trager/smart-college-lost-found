# FindIt — Smart College Lost & Found

FindIt is a front-end prototype for an AI-based lost and found item matching system for Smart College. It gives students and staff a simple way to report a lost or found item and browse recent reports.

## Features

- Responsive landing page designed for desktop and mobile
- Search and filters for all, lost, and found items
- Detailed item reports: category, colour, brand/label, location, date, approximate time, and distinguishing details
- Privacy reminder to keep sensitive identifiers out of public descriptions
- Demo matching logic that compares item name, colour, category, and location with opposite-type reports
- Example recent-item listings with useful identifying details

## Built with

- HTML5
- CSS3
- Vanilla JavaScript

No framework, package installation, or server is required.

## Run locally

1. Download or clone this repository.
2. Open `index.html` in any modern browser.

## Project files

```text
findit-smart-college/
├── index.html    # Page content and report form
├── styles.css    # Styling and responsive layout
└── script.js     # Search, filters, report modal, and matching demo
```

## Important note

This is a front-end demonstration for a college project. The matching score is a client-side prototype based on the report details; a production version would use a database, authentication, image uploads, and a backend or AI matching service.
